# Gaia synthetic photometry handoff

## Goal

Make Gaia DR3 synthetic photometry the primary reference for **every workflow that currently uses APASS anywhere in VaST**. Try a complete local Gaia Synthetic Photometry Catalogue (GSPC) installation first, then query the ESA Gaia Archive. If Gaia cannot supply enough usable matches in the requested band, try APASS DR9 via ESA TAP, APASS DR9 via VizieR, and finally Pan-STARRS1 via VizieR. The two supported Gaia deployments are a live ESA query and a full all-sky local copy. Keep the existing explicit Tycho-2 and astrometry-only modes.

## What is implemented

- [The APASS client](../lib/apass_esa_tap.sh) submits a bounded TAP request to `https://gea.esac.esa.int/tap-server/tap/sync`. It uploads the reference coordinates as a VOTable, searches `external.apassdr9` by `raj2000` and `dej2000`, and returns the brightest usable V-band match per target. The returned target ID maps directly back to the original solver star.
- [The solver](../src/solve_plate_with_UCAC5.c) tries the ESA client in `search_APASS()` before the existing VizieR APASS query. Invalid replies, transport failures, and fewer than four usable matches fall through to VizieR. The ESA result is applied only after the entire normalized response passes validation. Both APASS paths share the same missing-error defaults and Cousins R/I transformations through `set_apass_photometry()`.
- The runtime Gaia GSPC lookup, full-copy installer, and Gaia-first selection are the next implementation work.

## Gaia catalogue and queries

The ESA table is `gaiadr3.synthetic_photometry_gspc`. Join to `gaiadr3.gaia_source` on `source_id` for coordinates, reference epoch, proper motion, and relevant quality information. The GSPC provides Johnson B and V in `b_jkc_mag` and `v_jkc_mag`, Cousins R and I in `r_jkc_mag` and `i_jkc_mag`, and Sloan bands in `g_sdss_mag`, `r_sdss_mag`, and `i_sdss_mag`. Require a finite magnitude in the requested band and start with the corresponding flag equal to 1. Derive a magnitude uncertainty from the matching flux and flux error using `(2.5 / ln(10)) * flux_error / flux`, with positive flux. A live ESA join for a 0.25-degree cone centered at RA 291.769208 and Dec +15.467964 returned 20 validated I-band sample rows for Gaia G between 9 and 14. [ESA data model](https://gea.esac.esa.int/archive/documentation/GDR3/Gaia_archive/chap_datamodel/sec_dm_performance_verification/ssec_dm_synthetic_photometry_gspc.html) · [GSPC paper](https://arxiv.org/abs/2206.06215)

The full GSPC has 218,936,915 sources. ESA lists 44 gzipped CSV files totaling 41,976,759,812 bytes, about 42.0 GB or 39.1 GiB. That figure covers the synthetic photometry download. Budget separately for astrometry, installation workspace, and the local index. For the local backend, build a complete all-sky, release-versioned installation with coordinates joined by source ID. Validate the shard inventory and publish the index after the install completes. Review [the existing zone index](../src/catalogs/local_star_catalog.c) and [the nearby Gaia DR3 installer](../lib/install_local_copy_of_GaiaDR3_nearby_stars.sh) for patterns that suit large catalogues. [ESA bulk listing](https://cdn.gea.esac.esa.int/?prefix=Gaia/gdr3/Performance_verification/synthetic_photometry_gspc/) · [Catalogue statistics](https://gaia.aip.de/metadata/gaiadr3/synthetic_photometry_gspc/)
